Docker 是一种容器化技术。

## Image

Image 是容器运行的模板。

## Container

Container 是 Image 运行出来的实例。

## Network

Network 用于容器之间通信。

## Volume

Volume 用于持久化数据。

## Compose

Docker Compose 用一个配置文件描述多个服务，适合管理网站、数据库和反向代理等组合环境。
